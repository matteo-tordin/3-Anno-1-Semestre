SQL (**Structured Query Lenguage**) è il linguaggio standard per interagire con i DBMS.

Si compone di
* **Data Definition Langage DDL**
* **Data Manipulation Language DML**

SQL **implementa il modello relazionale** e l'algebra relazionale, con alcune estensioni.

Esiste uno standard ISO per regolare il linguaggio SQL.
